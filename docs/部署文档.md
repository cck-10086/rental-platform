# 部署文档：从本地到公网可访问

本文档说明如何让本项目不止在开发机本地运行，覆盖三种常见场景。先根据你的需求选方案，再按对应章节操作。

## 方案选择

| 场景 | 适用情况 | 难度 | 说明 |
| --- | --- | --- | --- |
| 方案 A：局域网访问 | 同一 WiFi 下的同学/手机访问 | 低 | 后端监听 0.0.0.0 + 前端生产构建由 Nginx 托管 |
| 方案 B：内网穿透 | 临时给校外演示/评审看 | 低 | 在方案 A 基础上加 ngrok/cpolar 隧道 |
| 方案 C：云服务器部署 | 长期公网使用 | 中 | 云服务器 + Nginx + 域名 + HTTPS（推荐） |

三种方案共用同一套生产构建流程：后端打成 jar + 前端 `npm run build` 出静态文件。

---

## 0. 生产构建前的准备

### 0.1 修改生产配置

项目根目录的 `deploy/` 下提供了示例，复制为正式配置并填入真实值：

```powershell
copy deploy\application-prod.yml.example rental-platform-backend\src\main\resources\application-prod.yml
```

生产配置要点（示例文件里已写好）：

- 数据库账号密码、DeepSeek Key 全部通过环境变量注入，禁止写死；
- 生产 CORS 只放行你的域名；
- JWT 密钥使用强随机值（可用 `openssl rand -base64 64` 生成）；
- 生产环境以 `--spring.profiles.active=prod` 启动。

### 0.2 检查端口与防火墙

- 后端：8088
- 前端：Nginx 80（HTTP）或 443（HTTPS）

Windows 防火墙放行或云服务器安全组放行对应端口。

## 方案 A：局域网访问

适合同一个 WiFi/局域网内的设备访问。

### 步骤

1. **打包后端**

```powershell
cd rental-platform-backend
mvn clean package -DskipTests
```

产物：`target/rental-platform-1.0.0.jar`。

2. **启动后端（绑定所有网卡）**

Spring Boot 默认监听 `0.0.0.0`，无需额外配置。设置环境变量后启动：

```powershell
$env:DB_USERNAME = 'root'
$env:DB_PASSWORD = '你的数据库密码'
$env:DEEPSEEK_API_KEY = '你的DeepSeek密钥'
$env:JWT_SECRET = '生产环境强随机密钥'
java -jar rental-platform-backend\target\rental-platform-1.0.0.jar --spring.profiles.active=prod
```

3. **构建前端**

```powershell
cd rental-platform-frontend
npm run build
```

产物：`rental-platform-frontend/dist/`。

4. **用 Nginx 托管前端并代理后端**

安装 Nginx（Windows 版解压即用），把 `deploy/nginx.conf.example` 复制到 Nginx 的 `conf/nginx.conf`，修改：

- `root` 指向 `dist` 的实际路径；
- `proxy_pass` 指向后端地址（本机就是 `http://127.0.0.1:8088`）；
- 需要 HTTPS 时参考方案 C。

5. **让局域网设备访问**

```powershell
ipconfig   # 查看本机局域网 IP，例如 192.168.1.100
```

同一网络的设备访问 `http://192.168.1.100`（Nginx 80 端口）。若访问不了，检查 Windows 防火墙是否放行 80 和 8088。

## 方案 B：内网穿透（临时公网访问）

在方案 A 已可局域网访问的基础上，加一条隧道即可让公网访问，适合远程演示。

推荐工具：

| 工具 | 特点 | 地址 |
| --- | --- | --- |
| ngrok | 免费额度、海外域名，国内访问可能慢 | https://ngrok.com |
| cpolar | 国内服务、速度较好，免费隧道 | https://www.cpolar.com |
| 花生壳 | 国内老牌 | https://hsk.oray.com |

以 cpolar 为例：

```powershell
cpolar http 80
```

它会输出一个公网地址（形如 `https://xxxx.cpolar.cn`），把这个地址给需要访问的人即可。

注意：免费隧道地址每次重启会变化；演示前再启动一次拿到新地址。如需固定域名需付费。

## 方案 C：云服务器部署（长期公网使用，推荐）

### 1. 购买与准备服务器

- 阿里云/腾讯云轻量应用服务器（2C2G 起步即可）；
- 操作系统选 Ubuntu 22.04 或 Windows Server（如果继续用 Windows 习惯，选 Windows）；
- 安全组放行 80、443，必要时放行 8088（测试用）；
- 安装 MySQL（或使用云数据库）、JDK 21、Nginx。

### 2. 部署后端

```bash
# 上传 jar 到服务器（如 /opt/rental）
scp rental-platform-backend/target/rental-platform-1.0.0.jar user@server:/opt/rental/

# 用 systemd 守护进程（推荐，开机自启+崩溃重启）
sudo tee /etc/systemd/system/rental.service > /dev/null <<'EOF'
[Unit]
Description=Rental Platform Backend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/opt/rental
Environment=DB_USERNAME=root
Environment=DB_PASSWORD=你的密码
Environment=DEEPSEEK_API_KEY=你的Key
Environment=JWT_SECRET=强随机密钥
ExecStart=/usr/bin/java -jar /opt/rental/rental-platform-1.0.0.jar --spring.profiles.active=prod
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now rental
sudo systemctl status rental
```

### 3. 部署前端

```bash
# 上传 dist 到服务器
scp -r rental-platform-frontend/dist user@server:/var/www/rental/

# Nginx 配置
sudo tee /etc/nginx/sites-available/rental > /dev/null <<'EOF'
server {
    listen 80;
    server_name 你的域名或服务器IP;

    root /var/www/rental;
    index index.html;

    # Vue Router history 模式回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端接口代理
    location /api/ {
        proxy_pass http://127.0.0.1:8088;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

sudo ln -s /etc/nginx/sites-available/rental /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 4. 配置域名与 HTTPS（推荐）

- 域名解析到服务器 IP；
- 使用 Let's Encrypt 免费证书：

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

certbot 会自动改写 Nginx 配置启用 HTTPS 并续期。

### 5. 生产安全清单

- 修改 MySQL 密码、MinIO 密钥、JWT 密钥、`admin` 账号密码；
- DeepSeek Key 用环境变量注入，不进代码仓库；
- 数据库只允许后端所在主机访问，不开放公网 3306；
- 定期更新依赖版本。

## 常见问题

**Q：局域网设备打不开页面？**

依次排查：Nginx 是否启动、80/8088 是否放行防火墙、手机和电脑是否同一网络、后端日志是否有报错。

**Q：页面能开但接口 404/502？**

检查 Nginx `location /api/` 的 `proxy_pass` 是否带正确地址；后端是否已启动且监听 8088。

**Q：刷新页面 404？**

Nginx 缺少 SPA 回退配置 `try_files $uri $uri/ /index.html;`。

**Q：公网访问但接口报 CORS？**

确认 `application-prod.yml` 中 CORS 允许来源包含你的访问域名，且前后端同域时（Nginx 代理）一般不会触发 CORS。
