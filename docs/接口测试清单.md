## 7. 运行单元测试

```bash
cd rental-platform-backend
mvn test
```

当前单测覆盖（24 个用例，全部通过）：

| 测试类 | 覆盖内容 | 用例数 |
| --- | --- | --- |
| `JwtUtilTest` | token 生成/解析、过期、篡改拒绝 | 3 |
| `SecurityUtilTest` | 未认证时获取用户抛出异常 | 1 |
| `UserServiceImplTest` | 重复注册、登录成功/失败/禁用、资料白名单更新 | 5 |
| `AdminServiceImplTest` | 非法角色拒绝、自我保护、密码重置加密 | 3 |
| `DeepSeekServiceImplTest` | TXT/PDF/docx 解析、审查解析失败重试后报错、空数组视为无风险 | 8 |
| `AiConversationServiceTest` | 会话列表聚合、会话详情、删除会话的归属校验 | 4 |

> 说明：JDK 25 下运行测试需要 pom 中已配置的 `-XX:+EnableDynamicAgentLoading -Dnet.bytebuddy.experimental=true`（Mockito 兼容 JDK 25），项目 pom 已内置。
