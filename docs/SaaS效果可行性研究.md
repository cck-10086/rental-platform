# SaaS 三栏聊天界面:可行性研究(2026-09-20)

> 问题:能否用现有技术栈达到"左侧垂直导航 + 中间会话列表 + 右侧聊天工作区 + 浅色/留白/蓝白/圆角/细边框/轻阴影/毛玻璃/层级清晰"的目标效果?
> 结论:**能,全部可在 Vue 3 + Element Plus 上实现,零新增依赖**。高保真设计稿见本次对话,本文记录依据与差距。

## 一、依据(三个 Skill 的研究结果)

1. **ui-ux-pro-max / Minimalism & Swiss Style**:该风格的官方配方就是本项目目标——大量留白、网格化、单一强调色、清晰层级、hover 200-250ms、阴影克制(WCAG AAA 可达)。本目标完全落在其"Best For: SaaS platforms"范围内。
2. **ui-ux-pro-max / Glassmorphism**:毛玻璃规范(blur 10-20px、1px 细边框、15-30% 透明度)与本项目现有实现一致;**前提是背后必须有内容/色彩可模糊**,纯色背景上玻璃不可见(当前已知的待修点)。
3. **shadcn / Chat & Messaging 规则**:给出了聊天工作区的行为蓝图——流式跟随(用户上滚即让位)、回到底部悬浮按钮、日期分隔(Marker)、消息行组合(头像/内容/时间)。这些是**行为模式**,不依赖其 React 组件,可用 Vue 组合式 API 等价实现。
4. **ui-ux-pro-max / UX 布局陷阱**:dvh 替代 vh、异步内容预留高度、z-index 分层管理——实施时的检查项。

## 三、当前状态与目标的差距(合计 7 项)

按对"效果可见度"排序:

1. **毛玻璃背景缺内容**(最大视觉差距):内容区是纯色,玻璃不可见 → 加两层 ≤7% 透明度的主色 radial 柔光
2. **对比度硬伤**:`#CBD5E1/#94A3B8` 作文字不达标 → 换 `#64748B` 及以上
3. **会话无分组**:按时间分组才能体现层级
4. **聊天行为缺件**:回到底部按钮、流式光标、快捷 chip 常驻(而非仅空态)
5. **语义色两套**:补 danger/warning/success 变量覆盖
6. **骨架屏缺失**:列表加载空白
7. **顶栏/页内标题重复**

## 四、实施路径(与《前端优化方案.md》三阶段合并)

- **第一步(试点,只动 1-2 个文件)**:`global.css` 补语义色+柔光底+对比度修正,同时改 `AiChat.vue` 到设计稿状态(分组+光标+回到底部+chip)→ **给用户看实物**
- 用户确认 → 铺开阶段 B(骨架屏/空态/标题)与阶段 C(侧栏折叠、列表页三段式)
- 每步 build + test 把关,未提交可随时回退
