# 功能优化执行简报（时间充裕版）

## 目标

在代码冻结前完成 8 项功能优化，将审查核心从"纯提示词工程"升级为 **"LLM + 规则引擎混合架构"**，补齐测试与反馈闭环短板，并以第五轮评测量化改进效果。完成后项目进入验收演示与文档撰写阶段。

## 任务清单

### 1. 定级规则引擎（约 1 天）

- 后端新增 `RiskRuleEngine`（service 层），在 AI 审查输出**存库前**做二次确定性校验
- 规则集（从四轮评测锚点提炼）：
  - R1 违约金日利率：`<1%/日` → 低；`1%–3%/日` → 中；`>3%/日` 或"三倍赔偿" → 高（AI 定级越界时修正）
  - R2 押金条款：`≤1 个月`且约定"验收无损坏退还" → 低；`>2 个月` → 中；"不予退还 / 以使用痕迹扣押" → 高
  - R3 强制高风险：放弃诉权、人身伤亡概不负责、单方随时涨租/解除 → 强制高
  - R4 正面条款降级：5 日维修、30 日书面通知、协商续约等被 AI 误标高时降级
- 修正记录：被修正条款标注 `correctedBy = rule_engine`，供统计与评测对照
- 每条规则一个单元测试（mvn test 覆盖）

### 2. 风险偏好可配置（约 0.5 天）

- 新增 `risk_config` 全局配置表（宽松 / 标准 / 严格三档），规则引擎启动时读取
- 三档只调整 R1/R2 的数值边界，R3/R4 关键词规则不受档位影响
- 管理后台加偏好设置项，切换后新审查立即生效（已存报告不追溯）
- 全局配置即可，用户级扩展写入"未来工作"

### 3. 审查结果缓存（约 0.5 天）

- 合同文件计算 SHA-256 指纹，上传时同用户查重
- 命中且已有"审查完成"记录 → 直接返回已有报告，不重复调用 AI
- 扫描件（OCR）同样适用；跨用户不共享缓存

### 4. 演示韧性兜底（约 0.5 天）

- AI 调用失败/超时：审查状态落"审查失败"而非 500，前端显示明确提示 + "重新审查"按钮
- 区分失败原因（网络 / 额度 / 服务不可用）透传到提示文案
- 消除验收演示现场的无穷 loading 与白屏风险

### 5. 误报反馈闭环·最小版（约 1 天）

- 审查报告页每条风险条款加"有用 / 误报"反馈按钮
- 后端新增 feedback 接口与表（record_id、类型、用户、时间），落库
- 管理后台显示统计："已确认 x 条 / 误报 y 条"
- **不做**模型侧自动学习——那是"未来工作"素材

### 6. 主链路 E2E 测试（约 1 天）

- Python Playwright 脚本入库（`rental-platform-frontend/e2e/`）
- 一条主链路：登录 → 上传合同 → 等待审查完成 → 打开报告 → 导出 PDF，断言各环节关键状态
- 放在功能定稿后编写，测最终形态

### 7. 第五轮评测（1–2 天，需双人裁决配合）

- medium 档锚点示例扩充后重跑全量评测脚本
- 量化对比：第四轮（纯 prompt）vs 第五轮（混合架构），产出第五轮评测报告
- 口径与前四轮完全一致，保证可比性
- 附带验证 medium 定级准确率是否回升

### 8. AI 顾问注入合同上下文（约 1 天）

- 用户存在已审查合同时，聊天系统提示注入其最近一份合同的 Top 5 风险摘要
- 无合同用户保持现状；摘要注入不改变通用咨询能力
- 聊天页加"已关联合同"标识（最小前端改动）

## 执行顺序与依赖

```
1 规则引擎 ──→ 2 风险偏好 ──┐
          ├──→ 3 缓存 ──→ 4 韧性 ──→ 5 反馈闭环 ──→ 6 E2E ──→ 7 第五轮评测 ──→ 8 AI 上下文
```

- 1 是地基；2 依赖 1；6 必须在 1–5 定稿后写；7 量化 1–5 全部改进；8 独立收尾
- 每项完成即独立提交（分批 commit，不混提）

## 全局技术约束

- 保持 Vue 3 + Element Plus + Spring Boot 技术栈不变
- 不删除、不改变既有 API 语义与表结构语义；只允许**新增**接口、字段、表（全部向后兼容）
- 不引入 React / Radix / Tailwind；前端改动复用现有设计令牌
- 所有新增文案与代码注释使用简体中文
- 不使用 `git reset` / `git checkout` 覆盖改动
- 后端改动跑 `mvn test`，前端改动跑 `npm run lint` / `npm test` / `npm run build`，全部通过后才提交

## 验收标准

1. 规则引擎每条规则有单测，`mvn test` 全绿
2. 偏好三档切换后，同一合同重审可见定级变化（附演示步骤）
3. 重复上传同一文件秒级返回已有报告（网络面板可见 0 次 AI 调用）
4. 断网/错 Key 场景前端有明确中文提示，无白屏无限等待
5. 误报反馈落库，管理后台统计可见
6. E2E 脚本一键运行全绿
7. 第五轮评测报告产出，含与第四轮的 F1 / 精确率 / 定级准确率对比
8. AI 顾问能正确回答"我上传的合同有什么风险"
9. 全程 lint / test / build / mvn test 通过，分批提交、提交信息规范

## 禁止项

- 换模型、微调、自建训练
- 误报的模型侧自动学习
- 继续打磨 UI 视觉
- 性能优化（无实际瓶颈）
- 任何破坏既有评测可比性的口径改动
