# 前端美化方案:简洁现代 SaaS 风格

> 状态:**待确认**。确认后按第 8 节顺序实施,全程不改业务逻辑、不新增 npm 依赖。

## 0. 三个 Skill 的融合结论

| Skill | 采纳内容 | 舍弃/变通内容 |
| --- | --- | --- |
| design-taste-frontend | 单主色原则、tinted 阴影、卡克制、完整交互态(骨架屏/空态/active 微缩)、弹性缓动 cubic-bezier(0.16,1,0.3,1)、禁止 emoji 图标、非纯黑文本 | 其 React/Tailwind/Framer-Motion 技术栈(本项目是 Vue 3 + Element Plus,不迁移);默认参数 8/6/4 太激进,按用户"专业高效简约"要求调为:设计差异度 3 / 动效强度 5 / 视觉密度 3-4 |
| ui-ux-pro-max | SaaS 蓝白 token(#2563EB/#F8FAFC/#1E293B)、毛玻璃规范(blur 10-20px、1px 细边框、对比度 4.5:1)、UX 清单(44px 触控、focus 可见、150-300ms 过渡、prefers-reduced-motion) | 检索出的青绿配色(用户明确要蓝白);Inter 字体(中文 UI 用系统栈更稳,且离线部署不能依赖 Google Fonts) |
| shadcn | 语义化 token 思想(所有组件从 CSS 变量取色)、组合优于自造(继续用 el-* 组件而不是手写 div)、聊天滚动行为统一收敛 | shadcn/ui 组件库本体(React 生态,引入等于重写前端) |

## 1. 设计令牌(global.css 定义 CSS 变量)

**颜色(蓝白 SaaS)**
- 页面底 `--rp-bg: #F8FAFC`(slate-50);卡片面 `--rp-surface: #FFFFFF`
- 毛玻璃面 `--rp-glass: rgba(255,255,255,0.78)` + `backdrop-filter: blur(14px)`
- 细边框 `--rp-border: #E2E8F0`(slate-200);分隔线 `--rp-divider: #F1F5F9`
- 主文本 `--rp-text: #1E293B`;次要 `--rp-text-secondary: #475569`;弱化 `--rp-text-muted: #64748B`(均满足 4.5:1)
- 主色 `--rp-primary: #2563EB`;hover `#1D4ED8`;浅底 `--rp-primary-light: #EFF6FF`

**形状与阴影**
- 圆角:卡片 14px、按钮/输入 10px、聊天气泡 16px(朝向角 4px)
- 轻阴影:`0 1px 2px rgba(15,23,42,0.04)`;悬浮层 tinted 阴影 `0 8px 24px -12px rgba(37,99,235,0.12)`(阴影带主色倾向,不用死黑)

**字体与动效**
- 系统字体栈:`-apple-system, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`;数字 `font-variant-numeric: tabular-nums`
- 过渡统一 `180ms cubic-bezier(0.16, 1, 0.3, 1)`,只动 transform/opacity;`prefers-reduced-motion` 时全部关闭

## 2. Element Plus 主题统一(零依赖换色)

在 global.css 覆盖 Element 的 CSS 变量:`--el-color-primary` 及其 light-3/5/7/9 系列映射到 #2563EB 蓝阶,统一 `--el-border-radius-base: 10px`、`--el-border-color: #E2E8F0`。**收益:全站 el-button/el-table/el-tag/el-input 一次换装,不用逐页改。**

## 3. Layout.vue:左侧垂直导航(浅色玻璃化)

- 侧栏从深色 `#304156` → 浅色毛玻璃(白 78% + blur 14px + 右侧 1px 细边框)
- Logo 区:主色圆角方块图标 + 字重 600 标题,左对齐
- 菜单项:圆角 9px 胶囊;激活态 = `#EFF6FF` 底 + 主色文字 + 左侧 3px 主色指示条;hover 浅灰底
- 顶栏:白 70% 毛玻璃 + blur + 底部细边框;左侧显示当前页面标题(信息层级),右侧用户头像下拉
- 主内容区:底色 `#F8FAFC`,内边距加大到 24-28px,留白更足

## 4. AiChat.vue:中间会话列表 + 右侧聊天工作区

- 整页改为**双栏玻璃卡**:中间会话列表卡(280px,白 82% 玻璃、14px 圆角、细边框、轻阴影)+ 右侧聊天卡
- 会话项:hover 浅蓝底;激活 `#EFF6FF` + 左侧主色条;标题单行截断,元信息(条数·时间)11px 弱化色
- 气泡:用户 = 主色实底(圆角 16px/右下 4px);AI = 白卡 + 细边框 + tinted 轻阴影(圆角 16px/左下 4px);最大宽度 72%
- 输入区:圆角 12px 卡片式输入框(聚焦时主色描边),右侧主色方形发送按钮;Enter 发送逻辑不变
- 空状态:居中玻璃卡 + 主色图标 + 3 个示例问题快捷 chip(点击直接填入提问)
- 打字三点指示保留,颜色换主色;滚动条细窄化(slate-300)
- 所有现有功能(流式输出、会话增删、markdown 渲染)不动

## 5. 其余页面统一(工作台/合同/房源/费用/维修/退租/管理后台)

- 统一页面头:左"标题+副标题"、右操作按钮区
- `el-card` 统一玻璃卡观感(白底、14px 圆角、细边框、轻阴影),可点卡片 hover 时上浮 1px
- 表格:外重边框去掉,表头 slate-50 底 + 12px 字重 500,行 hover `#F8FAFC`
- 状态标签统一为浅底深字圆角 tag(高风险红系/中琥珀/低绿系)
- 工作台统计卡:数字 22-24px 加粗 + tabular-nums,右上角浅蓝底圆角图标块;ECharts 配色对齐蓝阶+灰阶
- 列表加载用 `el-skeleton` 骨架屏,空态统一"图标+说明+主操作"

## 6. 交互态补全(taste-skill Rule 5)

- 按钮 `:active` 时 `scale(0.98)` 物理按压感
- 所有可点元素 `cursor: pointer` + `:focus-visible` 主色描边
- 表单 label 在输入框上方(现有页面逐步对齐,不强制一次性改完)

## 7. 明确不做的事(范围控制)

- 不迁移 Tailwind / shadcn-ui(React 生态,等于重写)
- 不新增任何 npm 依赖、不引入在线字体(离线/内网部署会挂)
- 不做暗色模式(本方案为浅色;token 已留扩展位)
- 移动端只做基础响应式(<768px 侧栏收窄为图标),不深度适配
- 登录/注册页:仅换主色与圆角(跟随 Element 变量自动生效),不做大改

## 8. 实施顺序

1. `global.css`:design tokens + Element Plus 变量覆盖(全站换色立竿见影)
2. `Layout.vue`:侧栏 + 顶栏玻璃化
3. `AiChat.vue`:双栏玻璃卡 + 气泡 + 输入区 + 空状态
4. 其余页面逐页统一卡片/表格/标签/骨架屏(只动模板与样式,不动逻辑)
5. 验证:`npm run build` + `npm test`(8 个用例必须全过)

涉及文件:`src/assets/global.css`、`src/views/*.vue`(样式与模板层);`src/api/*`、`store/*`、后端一概不动。
